# 会议实时翻译（日 ⇄ 中）

[中文](README.md) ｜ [English](README.en.md) ｜ [日本語](README.ja.md)

[![CI](https://github.com/Yang-Code01/meeting-translate/actions/workflows/ci.yml/badge.svg)](https://github.com/Yang-Code01/meeting-translate/actions/workflows/ci.yml)

Windows 桌面小工具，提供两个功能：

- **会议实时翻译**：监听**任意会议软件**的声音——系统环回当作【对方】，麦克风当作【我】——在本地做语音识别，再用 GitHub Copilot 或你自己的模型服务（OpenAI 兼容）翻译，把日中双语字幕显示在置顶悬浮窗里；会议结束后可以一键生成纪要、待办和清洗后的双语全文。
- **划词/句翻译**：在任意程序里选中一段日文，按 **Alt+M**，光标旁弹出中文译文与带假名注音的原文。它跑在一条独立且预先预热的会话上，不会打断正在进行的会议翻译。

不绑定会议平台（Teams / Zoom / Webex / Meet / 腾讯会议都行），不需要虚拟声卡，语音识别全程在本地 CPU 上跑，只有文本会发往你选择的模型服务。

## 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（依赖 WASAPI 环回采集） |
| 账号 | GitHub Copilot 订阅，或任意 OpenAI 兼容服务的 API key（翻译与摘要都由它完成） |
| 硬件 | 普通 x86-64 CPU 即可，无需独显；识别默认占 4 线程 |
| 麦克风 | 可选。开启后你自己的话会以【我】标记，需要戴耳机 |

## 安装

### 方式一：下载打包好的 exe

1. 到 [Releases](https://github.com/Yang-Code01/meeting-translate/releases/latest) 下载 `MeetingTranslate.exe`（约 400 MB，内置识别模型与 Copilot 运行时）。
2. 双击运行。首次启动要解压内置资源，约 15 秒；就绪后右下角出现「译」托盘图标。
3. 首次使用需登录 Copilot（见下方[登录](#登录-copilot)），或在设置里改用自己的 API key。

程序不写注册表、不需要管理员权限；卸载就是删掉 exe 和 `%APPDATA%\meeting-translate\`。

### 方式二：从源码运行

需要 [uv](https://docs.astral.sh/uv/) 与 Python 3.12 以上（开发机使用 3.14）。

```powershell
uv sync
uv run python scripts/fetch_models.py   # 下载识别模型到 models/（约 380 MB）
uv run python main.py                   # 运行，需已登录 Copilot
```

`uv.lock` 中记录的包索引是本机使用的清华镜像（`pypi.tuna.tsinghua.edu.cn`）。国内网络可直接 `uv sync`；**海外网络**请先删除 `uv.lock` 再执行 `uv sync`，让它按 `pyproject.toml` 之外的默认源重新解析，或改用：

```powershell
uv sync --index-url https://pypi.org/simple --refresh
```

### 登录 Copilot

未登录时启动会弹出引导，二选一：

- **方式一（推荐）**：本机装有 `copilot` CLI → 点「打开控制台执行 copilot login」，在弹出控制台完成登录后点「我已完成登录，重新检测」。
- **方式二**：粘贴 fine-grained Personal Access Token（需勾选 **Copilot Requests** 权限）。

### 使用自己的模型服务（自带 API key）

不想用 Copilot，或者要接自己的端点：

1. 设置 →「模型服务」选「自定义（OpenAI 兼容）」→「新建…」。
2. 填名称、接口地址（例如 `https://api.deepseek.com/v1`）、模型名（例如 `deepseek-chat`）和 API key；单价留空就不折算金额。
3. OK 后立即生效，不需要重启程序。

- 任何实现 `/chat/completions` 的服务都能接：DeepSeek、Kimi、通义、OpenAI、Ollama、vLLM、公司网关。
- API key 用 Windows DPAPI 加密后写进 `config.json`；换机器或换 Windows 用户需要重新输入。
- 用量按 token 计：悬浮窗显示本场输入/输出 token，填了单价才折算金额；自定义端点没有账户级配额可查。
- 会话历史由本机维护，每句都会带上历史重发，token 消耗随会议时长增长；会话轮换间隔可在设置里调。
- 内网自签证书的端点可以在该条配置里勾选「忽略证书校验」，只对这一条生效；公网端点不要开。
- 会议中切换服务商：先用旧后端生成前情摘要，再用新后端建会话；失败则继续用旧会话。

## 使用

### 开一场会

1. 按 **Ctrl+Alt+J**（或托盘菜单、悬浮窗上的「▶ 开始」）开始翻译；再按一次暂停，按「▶ 继续」恢复。
2. 悬浮窗里日文实时滚动，一句话说完（VAD 判定静音）后追加中文译文；【对方】和【我】各自独立成句。
3. 点「■ 结束」结束会议，随后会询问是否做会后整理。

翻译方向在设置里切换（日→中 / 中→日），**会议进行中锁定**，从下一次「开始」生效。中→日固定使用 SenseVoice 识别中文，术语表反向用于提示词，纪要与待办用日文书写。

### 悬浮窗与托盘

- 悬浮窗置顶、半透明，可拖动，也可拖四角缩放；双击窗口边缘在全屏与原来的大小之间切换。字号与不透明度在设置里调。
- 「—」隐藏到托盘，托盘菜单「显示/隐藏字幕窗」可再打开；设置里关掉「显示悬浮字幕窗」后，启动时只留托盘图标和快捷键。
- 设置里可开启「字幕模式」：悬浮窗只显示译文，不显示原文和未完成片段，适合把窗口当视频字幕使用。
- 「🎤 麦克风」按钮控制是否采集你自己的声音，状态会记住，会议中切换立即生效。
- 托盘菜单：开始/暂停、结束会议、显示/隐藏字幕窗、设置、模型（快速切换）、编辑术语表、打开记录文件夹、整理历史会议、登录 Copilot、退出。
- 设置窗口是非模态的，打开时悬浮窗仍可操作；改动任一设置项后 OK 按钮左侧会提示「设置已修改，点击 OK 后生效」，不点 OK 直接关闭则丢弃修改。悬浮窗可见时，设置窗口会放在悬浮窗旁空间最大的一侧。

### 划词/句翻译（Alt+M）

在**任意程序**里选中一段日文，按 **Alt+M**（可改），光标旁会弹出小窗，显示中文译文与带假名注音的原文：

```
会議の資料を送ります
会議（かいぎ）の資料（しりょう）を送（おく）ります
```

- 中文译文、假名、汉字三行可分别调字号与颜色，也可以关掉汉字行只看假名。
- 弹窗大小可拖动，下次记住。
- 翻译使用一条独立且预先预热的会话，不会打断会议中的翻译链路。
- 记录会累积在内存里，点设置里的「保存划词/句翻译历史」才写入 `selection_translation_history.md`（自动去重）。

> 工作原理：按下快捷键后程序会模拟一次 Ctrl+C 读取当前选区，然后恢复你原来的剪贴板内容。所以**先选中文本，再按快捷键**。

### 断句与语气词

- **断句**：VAD 静音 0.6 秒算一段；句子以 て/が/けど/ので 等结尾、或只有 1–3 个字时视为「没说完」，暂存等待后续（中文对应 的/和/但是/因为 等）。最多等 3 秒，合并后累计超过 20 秒也会送翻译；单句超过 10 秒强制切分。三项都可在设置里调。
- **语气词**：え/あ/えー/えーと/あの/うん/ん 这类单独成句时只显示原文、不翻译；中文列表（嗯/啊/呃/那个 等）单独维护。两个列表都能在设置里编辑。
- **回声去重**：麦克风开着又没戴耳机时，麦克风会录到对方的声音。程序会丢弃 4 秒内与【对方】相似度 ≥ 0.75 的【我】句子，但这只是兜底——请戴耳机。

### 术语表

托盘菜单「编辑术语表」，每行一条：

```
取引種別            # 不写译法 = 保留原词
リリース = 发布      # 指定译法
```

术语会同时进入翻译提示词和识别热词。修改后从下一次「开始」生效。

> 热词只对 **ReazonSpeech** 引擎起作用；默认的 SenseVoice 不支持热词，但术语表仍会约束翻译。

### 模型与用量

- 设置里按估算成本从低到高列出全部可用模型，每项注明约多少 AIC/时、是基准模型的几倍、平均延迟；「测速」可实测当前选中的模型。
- 会议中切换模型立即生效：程序先用旧模型生成前情摘要，新会话携带摘要、最近 5 句和术语表，预热后再切换。
- 所选模型不支持所选推理强度时会自动降档并在状态栏提示。
- 悬浮窗默认显示「账户已用 AIC」「本场 AIC」；「账户剩余 %」默认不显示，可在「显示设置」里开关；剩余低于 10% 时不论开关都会以红色显示，但不会中断会议。
- 使用自定义端点时，悬浮窗与会议记录改显示本场输入/输出 token；填了单价才折算金额，账户配额一栏不再出现。
- 整场会议共用一个会话，每 30 分钟轮换一次（可调）；每次请求都会携带当前会话的历史，这是可控的额度消耗来源。

### 会后整理

结束会议时会问到「现在整理纪要、待办和清洗后的双语全文吗？」：

- 整理期间悬浮窗显示分阶段进度，完成后自动打开整理稿并弹出托盘通知；失败可点「重试」。
- 整理稿命名：`<AI 提炼的标题>_<生成时间>.md`，例如 `订单缺陷复盘_2026-10-14_140530.md`。
- 双语记录为 `<会议开始时间>.md`，与整理稿放在同一目录。
- 托盘菜单「整理历史会议…」可以对**已有的双语记录**再做一次整理（会把整理稿当作无效输入拒绝）。

### 设置项的生效时机

| 立即生效 | 下一次「开始」生效 |
|---|---|
| 翻译模型、推理强度、麦克风开关、模型服务与端点 | 音频设备、翻译方向、识别引擎、识别纠错、断句三项、会话轮换间隔 |

## 数据位置

全部在 `%APPDATA%\meeting-translate\`，不上传任何地方：

| 文件 | 内容 |
|---|---|
| `config.json` | 设置（自定义端点的 API key 经 Windows DPAPI 加密后存在这里） |
| `model_stats.json` | 各模型实测延迟与历史用量（用于估算成本） |
| `glossary.txt` | 术语表 |
| `selection_translation_history.md` | 划词/句翻译历史（手动保存后才写入） |
| `transcripts\` | 会议中的临时记录；未设定保存目录时的默认位置 |
| `models\` | 可选下载的识别模型（exe 版无需下载） |
| `app.log` | 日志 |

会议结束后只保留 Markdown：双语记录 `<会议开始时间>.md` 与整理稿 `<标题>_<时间>.md` 写到设置的保存目录（首次结束时询问，取消则本次留在默认目录、下次再问）。临时 `.json` 在整理完成或放弃后删除；整理失败时保留以便重试。

## 隐私与使用注意

- **录音需要同意**。各地法规不同，录制会议音频前请自行取得参会者同意。
- 识别出的**文本**会发送到你在设置里选择的模型服务：默认是 GitHub Copilot（GitHub / Microsoft），也可以是你自己配置的 OpenAI 兼容端点。音频本身不会离开本机。本程序不收集任何遥测，也不向作者回传数据。
- 使用第三方端点时，会议文本会交给对应服务商，其留存与是否用于训练由该服务商决定；内置模板里标注了常见服务商的政策，涉密会议请自行确认后再用。
- 日志、记录、术语表全部只在你本机的 `%APPDATA%` 目录里。
- 麦克风无法区分说话人：旁边有人说话也会被记成【我】。不适合的场景请关闭麦克风按钮。
- 程序不修改系统音频设置、不安装驱动。

## 已知限制

- 仅 Windows：采集依赖 WASAPI 环回，没有跨平台计划。
- 默认走 Copilot 时需要订阅，额度按 AIC 与请求次数计；改用自定义端点后按 token 计费，额度由服务商决定。
- 默认引擎 SenseVoice 不支持热词；需要热词请切到 ReazonSpeech（更慢一些）。
- 说话人区分只做到「对方 / 我」两路，无法区分会议室里的多个人。
- exe 约 400 MB，启动要解压，首启约 15 秒。
- 暂停会强制把当前句子定稿，句中暂停可能截断半句。

## 技术要点

- **先切句再识别**：sherpa-onnx 整段送入只会输出最后一句，所以用 silero VAD 先切（默认静音 0.6 秒、单句上限 10 秒），再逐句解码；日语 SenseVoice 在 4 线程 CPU 上单句解码约 0.35 秒。
- **未说完的话要合**：只靠静音切句会把「〜ですが／〜ので」切碎，于是再加一层日语句末判定 + 3 秒等待 + 20 秒合并上限，合并后按一条翻译和显示。
- **一次请求干两件事**：翻译时让模型在同一次响应里先校正识别错的原文、再给译文，不额外消耗请求次数；校正结果覆盖显示与记录。
- **成本可见**：把每个模型的实测延迟与 AIC 单价折算成「约多少 AIC/时」写进设置列表，模型可现场测速。
- **划词翻译独立会话**：与会议翻译互不干扰，且提前预热，按下快捷键即可出结果。

## 开发

```powershell
uv sync
uv run python scripts/fetch_models.py   # 下载 ReazonSpeech + SenseVoice + silero VAD 到 models/

```

## 打包

```powershell
uv run python main.py        # 先运行一次，让 SDK 把 Copilot 运行时下载到 %LOCALAPPDATA%
uv run pyinstaller meeting-translate.spec --noconfirm
# 产物：dist\MeetingTranslate.exe
```
